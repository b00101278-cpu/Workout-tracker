# Workout-tracker
This code will allow you to make a log of workouts and calculate your macros for a day/meal.



Follow to UI by inserting name and bodyweight (ID gets automatically generated)
You can leave name blank if you want it anonymous.

Numerically pick an option:

- option 1: pick an exercise and enter details based on exercise:
Machine: Checks if unilateral, bilateral. Weight increments (jumps in weight e.g, each weight jump is 2.5kg)
Free weight: Equipment used (barbell, dumbbell, kettlebell)
Calisthenics: Portion of bodyweight used.
Modified calisthenics: extends calisthenics to take into consideration external factors like increased or decreased resistance through band, belt, etc.

- option 2: logs the workout to a file named WorkoutLog.txt

- option 3: You should create a file named FoodLog.txt and insert the macros in the form: name, protein, carbs, fat (e.g, Chicken Breast, 30, 1, 2) and the calories will be calculated automatically.

- option 4: Close program
